# Student Entity

Represents an enrolled or prospective student profile converted from a [[Lead Entity]].

## 📋 Schema Attributes
- `fullName`, `email`, `phone`, `nationality`, `countryOfResidence`
- `passportNumber`, `passportExpiry`
- `academicHistory` (Degree titles, GPA, graduation years)
- `englishProficiency` (IELTS, TOEFL, PTE, Duolingo, MOI)
