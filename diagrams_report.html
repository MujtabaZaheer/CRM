Role-Based Stage Authorization Matrix

Complete 20-Stage Ownership Rules Enforced in stageAuthorization.ts
RBAC Specification
4. Authorized Role Permissions by Stage
Single source of truth governing who is authorized to transition applications into each milestone stage.
Application Stage Department Authorized User Roles Operational Logic & Responsibility
Draft Counselling counsellor, team_leader, office_manager, Admins Initial applicant file creation and document assembly.
Initial Review / Documents Pending Counselling counsellor, team_leader, office_manager, Admins Document audit, prerequisites verification, requesting missing items.
Ready for Submission / Submitted Counselling counsellor, team_leader, office_manager, Admins Final check and formal dispatch to university admissions portal.
University Reviewing / Additional Info Admissions admissions_officer, university_partner, Admins Academic assessment and evaluation of institution entry requirements.
Conditional Offer / Unconditional Offer Admissions admissions_officer, university_partner, Admins 1-Click fast decision approval; automatically routes to Finance Desk queue.
Deposit Pending Finance finance_officer, Admins Generate tuition deposit invoice / challan; student notified via in-app alert.
Deposit Paid Finance finance_officer, Admins 1-Click payment verification; marks fee cleared and forwards file to Visa Desk.
CAS / COE Pending / CAS Issued Visa visa_officer, Admins Verification and logging of CAS reference numbers from the institution.
Visa Preparation / Visa Submitted Visa visa_officer, Admins Embassy application lodgement and financial documentation clearance.
Visa Approved Visa visa_officer, Admins Visa grant confirmed; student immigration cleared for flight.
Enrolled Admissions admissions_officer, team_leader, Admins Physical university arrival, campus registration, and commission eligibility.
Universal Override (All 20 Stages) Admin platform_super_admin, org_admin Platform-wide emergency override, audit corrections, and supervisory adjustments.
