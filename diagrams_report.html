4. Role-Based Stage Authorization Matrix

Application Stage Responsible Department Authorized User Roles Description & Permissions
Draft / Review / Submitted Counselling counsellor, team_leader, office_manager Student onboarding, document verification, application submission to university.
Conditional / Unconditional Offer Admissions admissions_officer, university_partner Academic assessment, prerequisite evaluation, and issuing offer letters.
Deposit Pending / Deposit Paid Finance finance_officer Generating tuition fee challan, verifying payment receipts, fee clearance.
CAS Issued / Visa Submitted / Approved Visa visa_officer CAS/COE logging, embassy visa lodgement, and immigration grant clearance.
Universal Override (All Stages) Admin platform_super_admin, org_admin Full operational oversight and administrative exception management across all stages.
